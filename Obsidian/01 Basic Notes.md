### Linking Notes

use `[[ ]]` around the word or page title to link it with the current page
This page is linked with [[01 Basic Notes|Basic Notes]]
Clicking on it will take to the respective page and if page does not exist, it will create a new page with the same title

you can also use drag and drop feature to import files and others here

to open a link 
- `click` on the link to open it
- `ctrl + click` to open the link in new tab
- `ctrl + alt + shift + click` to open the link in new window
### Hotkeys
you can find the hotkey for a command by searching for the command in the command palette
you can also define the custom hotkey for a command
to add, alter or remove the hotkeys, `Settings => Hotkeys`

### Pop-Out Window and Tab groups
Can open any file in another pop out windows and move items between them. Closing the vault windows will also close the pop out windows of the vault.

you can move icons in the **ribbon** which is the vertical bar on Extreme Left by dragging and dropping and use right click menu to add or remove the icons

can split the tabs and pin the tabs from the right click menu, can change the size of tabs in tab group from the edge
can also use **Command Palette** `Ctrl + P => Move Current tab to new Windows`
Hotkeys related to tabs just work like Brave Browser
